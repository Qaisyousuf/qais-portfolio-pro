# Qais Yousuf — Portfolio

Portfolio for Qais Yousuf, a software engineer and product builder working with Nordic and European companies.

## Development

```bash
npm install
npm run dev
```

Use `npm run lint` and `npm run build` before shipping changes.

## Profile image and icons

`public/profile.jpg` is currently a neutral QY placeholder. Replace it with the final square profile photograph using the same filename; the navbar will update without code changes.

When the final photograph is available, also replace `src/app/icon.png` and `src/app/apple-icon.png` with square crops derived from it.
